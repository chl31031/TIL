# ☕ Java — 배열(Array)과 정렬(Sorting) 완벽 정리

## 01. 배열 (Array)

### 1-1. 배열의 특징

배열은 **같은 자료형**의 데이터를 연속된 메모리 공간에 저장하는 자료구조입니다.

- **인덱스**: 0부터 `length - 1`까지 사용합니다.
- **고정 크기**: 한 번 생성하면 크기를 변경할 수 없습니다.
- **Heap 영역**: `new` 키워드로 생성되며, 참조 변수는 힙 영역의 주소값을 가집니다.

### 1-2. 선언 및 초기화

```java
int[] arr = new int[5]; // 기본값(0)으로 초기화된 크기 5의 배열
int[] arrWithValues = {10, 20, 30, 40, 50}; // 선언과 동시에 초기화
```

### 1-3. 배열 복사 (Shallow vs Deep Copy)

- **참조 복사(Shallow)**: 주소값만 복사하여 같은 배열을 공유합니다.
- **깊은 복사(Deep)**: 새로운 배열 객체를 만들어 값을 일일이 복사합니다. (`System.arraycopy()`, `Arrays.copyOf()`)

## 02. 2차원 배열 (2D Array)

2차원 배열은 **배열의 배열**로, 행(row)과 열(column)로 구성된 표 형태입니다.

### 2-1. 가변 배열 (Jagged Array)

자바에서는 각 행마다 열의 길이를 다르게 지정할 수 있습니다.

```java
int[][] jagged = new int[3][];
jagged[0] = new int[2];
jagged[1] = new int[4];
```

## 03. 정렬 알고리즘 (Sorting Algorithms)

### 3-1. 버블 정렬 (Bubble Sort)

인접한 두 원소를 비교하여 큰 값을 뒤로 보내는 방식입니다. 구현이 매우 단순하지만 성능은 낮습니다.

### 3-2. 선택 정렬 (Selection Sort)

전체에서 **최솟값**을 찾아 맨 앞의 원소와 교환하는 방식입니다. 버블 정렬보다 교환 횟수가 적습니다.

### 3-3. 삽입 정렬 (Insertion Sort)

현재 원소를 이미 정렬된 앞부분 구간의 적절한 위치에 **삽입**하는 방식입니다. 데이터가 거의 정렬된 상태일 때 매우 빠릅니다($O(n)$).

---

## 📊 정렬 알고리즘 비교 테이블

| 알고리즘      | 핵심 동작              | 최선 시간복잡도 | 평균/최악 시간복잡도 | 특징                    |
| :------------ | :--------------------- | :-------------- | :------------------- | :---------------------- |
| **버블 정렬** | 인접 원소 비교 및 교환 | $O(n^2)$        | $O(n^2)$             | 구현이 가장 단순함      |
| **선택 정렬** | 최솟값 선택 후 교환    | $O(n^2)$        | $O(n^2)$             | 교환 횟수가 적음        |
| **삽입 정렬** | 정렬된 구간에 끼워넣기 | $O(n)$          | $O(n^2)$             | 거의 정렬된 배열에 최적 |

## 💡 핵심 요약

1.  **배열의 경계**: `ArrayIndexOutOfBoundsException`을 방지하기 위해 인덱스 범위를 항상 체크해야 합니다.
2.  **유틸리티 활용**: 배열의 출력은 `Arrays.toString()`, 정렬은 `Arrays.sort()`를 활용하면 편리합니다.
3.  **알고리즘 선택**: 데이터의 양이 적거나 이미 정렬된 상태라면 삽입 정렬이 효율적이며, 대량의 데이터는 자바 내장 정렬(`Dual-Pivot Quicksort` 등)을 권장합니다.
