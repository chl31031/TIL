# JavaScript BOM(Browser Object Model) 제어 

## 1. BOM(Browser Object Model)이란?
BOM은 웹 브라우저 창 자체를 제어하기 위한 객체 모델입니다. 최상위 객체인 `window`를 통해 브라우저가 제공하는 다양한 기능에 접근할 수 있습니다.
* `window`는 전역 객체이므로 `window.alert()` 대신 `alert()`처럼 생략하여 사용 가능합니다.

---

## 2. 사용자 대화 상자
사용자와 상호작용하기 위한 가장 기본적인 메서드입니다.

| 메서드 | 역할 | 반환값 |
| :--- | :--- | :--- |
| **`alert()`** | 단순 메시지 출력 | 없음 |
| **`confirm()`** | 확인/취소 질문 | `true` (확인), `false` (취소) |
| **`prompt()`** | 텍스트 입력 받기 | 입력한 문자열 (취소 시 `null`) |

---

## 3. 페이지 주소 제어 (`location` 객체)
현재 페이지의 URL 정보를 다루며, 페이지 이동 및 새로고침에 핵심적인 역할을 합니다.

* **`location.href`**: 새로운 URL로 이동합니다. (가장 많이 사용)
* **`location.replace(url)`**: 현재 페이지를 새로운 페이지로 대체합니다. **히스토리에 남지 않아** 뒤로가기가 불가능하므로 보안이나 결제 완료 페이지 등에서 유용합니다.
* **`location.reload()`**: 현재 페이지를 새로고침합니다.

---

## 4. 방문 기록 제어 (`history` 객체)
브라우저의 뒤로가기/앞으로가기 버튼과 같은 기능을 구현할 때 사용합니다.

* `history.back()`: 이전 페이지로 이동.
* `history.forward()`: 다음 페이지로 이동.
* `history.go(n)`: 인자값만큼 페이지를 이동 (예: `-1`은 뒤로가기, `2`는 두 페이지 앞으로).

---

## 5. 기타 정보 객체
* **`navigator`**: 사용자의 브라우저 정보, 운영체제, 언어 설정 등을 확인합니다.
* **`screen`**: 사용자의 모니터 화면 해상도, 색상 깊이 등의 정보를 제공합니다.
