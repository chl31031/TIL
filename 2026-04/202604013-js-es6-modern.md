# 🟨 JavaScript ES6+ 핵심 문법 정리 

### 1. 클래스 (Class)
ES6에서 도입된 객체 생성을 위한 새로운 설계도 양식입니다.

* **구조**: `constructor`는 인스턴스 생성 시 딱 한 번 실행되며, 메서드는 `prototype`에 저장되어 메모리를 효율적으로 사용합니다.
* **주의**: `new` 키워드 없이 호출하면 에러가 발생합니다.

---

### 2. 화살표 함수 (Arrow Function)
함수를 간결하게 표현하며, 특히 `this` 바인딩 방식이 일반 함수와 다릅니다.

* **문법 단축**: 
    * 본문이 한 줄이면 `return` 생략 가능.
    * 매개변수가 하나면 `()` 생략 가능.
    * 객체 반환 시에는 반드시 `({ id, name })`처럼 소괄호로 감싸야 함.
* **this 특징**: 자신만의 `this`를 가지지 않고 **상위 스코프의 `this`를 그대로 계승**합니다.
    * **권장**: 콜백 함수(forEach 등) 내부에서 외부 객체의 속성에 접근할 때 유용.
    * **주의**: 객체의 메서드를 화살표 함수로 정의하면 `this`가 전역 객체를 가리키므로 지양해야 함.

---

### 3. 이터러블 (Iterable)
'순회 가능한' 데이터 컬렉션을 위한 통일된 규약입니다.

* **특징**: `for...of` 반복문을 사용할 수 있습니다. (배열, 문자열, NodeList 등)
* **유사 배열 객체**: 인덱스와 `length`는 있지만 이터러블이 아닌 객체입니다. `Array.from()`을 통해 진짜 배열로 변환하여 사용합니다.

---

### 4. Rest 파라미터 & Spread 문법
똑같은 `...`을 사용하지만 쓰임새는 정반대입니다.

* **Rest Parameter**: 함수의 매개변수 끝에서 여러 인수를 하나의 **배열로 모을 때** 사용합니다.
* **Spread Syntax**: 배열이나 객체의 요소를 **낱개로 펼칠 때** 사용합니다.
    * 배열/객체의 **얕은 복사(Shallow Copy)** 및 병합에 매우 유용합니다.

---

### 5. 구조 분해 할당 (Destructuring)
배열이나 객체의 속성을 분해하여 개별 변수에 즉시 할당하는 문법입니다.

* **배열**: **순서**가 기준이며, 쉼표(`,`)로 요소를 건너뛰거나 Rest 파라미터로 나머지를 모을 수 있습니다.
* **객체**: **키(Key) 이름**이 기준이며, `:`을 사용해 변수명을 변경하거나 `=`로 기본값을 설정할 수 있습니다.
* **함수 매개변수 활용**: 인자로 객체를 전달받을 때 필요한 속성만 바로 추출하여 가독성을 극대화합니다.
