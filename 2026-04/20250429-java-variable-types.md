# ☕ Java — 변수, 상수, 그리고 형변환

## 1. 변수 (Variable)와 상수 (Constant)

### ① 변수 (Variable)

- **정의**: 값을 저장할 수 있는 메모리 공간. 프로그램 실행 중 값이 변할 수 있습니다.
- **선언 방식**: `타입 변수명 = 초기값;`
  ```java
  int age = 25;
  age = 26; // 값 변경 가능
  ```

### ② 상수 (Constant)

- **정의**: 한 번 저장하면 변경할 수 없는 변수.
- **선언 방식**: `final` 키워드를 사용하며, 관례적으로 대문자를 사용합니다.
  ```java
  final int MAX_SPEED = 120;
  // MAX_SPEED = 150; // 컴파일 에러 발생
  ```

## 2. 오버플로우 (Overflow)

변수가 표현할 수 있는 범위를 넘어설 때 발생하는 현상입니다.

- **원리**: 데이터의 최댓값을 넘어서면 다시 최솟값으로 돌아가고, 최솟값보다 작아지면 최댓값으로 돌아갑니다 (순환 구조).
- **예시 (byte 타입: -128 ~ 127)**:
  ```java
  byte b = 127;
  b++; // 결과: -128 (오버플로우 발생)
  ```

---

## 3. 형변환 (Typecasting)

데이터 타입을 다른 타입으로 변환하는 과정입니다.

### ① 자동 형변환 (Implicit Casting)

- **원리**: 작은 타입에서 큰 타입으로 변환될 때 Java가 자동으로 처리합니다. (데이터 손실 없음)
- **순서**: `byte` → `short`/`char` → `int` → `long` → `float` → `double`

### ② 강제 형변환 (Explicit Casting)

- **원리**: 큰 타입에서 작은 타입으로 변환할 때 사용자가 직접 명시합니다. (데이터 손실 가능성 있음)
- **방식**: `(타입)값`
  ```java
  double d = 3.14;
  int i = (int)d; // 결과: 3 (소수점 이하 손실)
  ```

## 4. 설정 정보 (Project Vcs Mapping)

IntelliJ 등에서 상위 디렉토리를 Git 저장소로 인식시키기 위한 설정값입니다.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project version="4">
  <component name="VcsDirectoryMappings">
    <mapping directory="$PROJECT_DIR$/.." vcs="Git" />
  </component>
</project>
```

## 💡 핵심 요약

1.  **변수는 변화하고 상수는 고정된다**: `final`은 값의 수정을 막는 안전장치다.
2.  **타입의 크기를 고려하라**: 정수 연산 시 결과값이 해당 타입의 범위를 넘지 않는지 확인해야 한다(오버플로우 주의).
3.  **캐스팅의 책임**: 강제 형변환 시 데이터 유실이 발생할 수 있으므로 주의해서 사용해야 한다.
