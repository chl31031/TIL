# ⚡ JavaScript — 이벤트 핸들러 및 이벤트 전파 완벽 가이드

## 1. 이벤트 핸들러 등록 방식

### ① 이벤트 핸들러 어트리뷰트 (구식)

HTML 태그에 직접 `onclick`과 같은 속성을 작성합니다.

- **단점**: HTML과 JS가 섞여 유지보수가 매우 어렵습니다. (현재 사용 비권장)
- **예시**: `<button onclick="alert('Hello')">클릭</button>`

### ② 이벤트 핸들러 프로퍼티 (과도기)

요소 객체의 프로퍼티에 함수를 직접 할당합니다.

- **특징**: HTML과 JS를 분리했으나, **하나의 이벤트에 오직 하나의 함수**만 연결할 수 있습니다.
- **예시**: `btn.onclick = function() { ... };`

### ③ `addEventListener` (현대적인 표준) 🚀

가장 권장되는 방식으로, 유연하고 강력합니다.

- **장점**: 하나의 이벤트에 여러 개의 핸들러를 등록할 수 있습니다.
- **구문**: `element.addEventListener('이벤트종류', 실행할함수)`
- **예시**: `btn4.addEventListener('click', mission);`

---

## 2. 이벤트 핸들러 제거하기

이벤트를 제거할 때는 등록할 때 사용했던 **함수의 참조(이름)**를 정확히 전달해야 합니다.

> **주의**: 익명 함수로 등록한 이벤트는 제거할 수 없습니다.

```javascript
// 등록
btn4.addEventListener("click", mission);

// 제거
btn4.removeEventListener("click", mission);
```

## 3. 이벤트 전파(Propagation)와 위임(Delegation)

### ① 이벤트 버블링 (Event Bubbling)

하위 요소에서 발생한 이벤트가 마치 물속의 거품처럼 부모 요소를 타고 최상위(`window`)까지 올라가는 현상입니다.

### ② 이벤트 위임 (Event Delegation)

버블링 현상을 역이용하여, 자식 요소마다 이벤트를 달지 않고 **부모 요소에 단 하나의 이벤트 핸들러만 등록**하여 자식들의 이벤트를 공통으로 처리하는 효율적인 기법입니다.

---

## 4. 이벤트 제어: 기본 동작 및 전파 방지

| 메서드                  | 설명                                       | 활용 예시                                             |
| :---------------------- | :----------------------------------------- | :---------------------------------------------------- |
| **`preventDefault()`**  | 브라우저의 기본 동작을 막음                | 폼 제출 시 새로고침 방지, 링크 클릭 시 이동 방지      |
| **`stopPropagation()`** | 이벤트가 부모로 전파(버블링)되는 것을 막음 | 모달 내부 클릭 시 배경 클릭 이벤트가 발생하는 것 방지 |

## 5. 마우스와 키보드 이벤트

### 🖱️ 마우스 이벤트

사용자의 마우스 동작에 반응합니다.

- `click`: 클릭 시
- `mousedown` / `mouseup`: 누를 때와 뗄 때
- `contextmenu`: 우클릭 시 (보통 `preventDefault`와 함께 사용)

```javascript
mouseBtn.addEventListener("contextmenu", (e) => {
  e.preventDefault(); // 브라우저 기본 우클릭 메뉴 차단
  $mouseArea.innerHTML += `우클릭 이벤트 발생!<br/>`;
});
```

### ⌨️ 키보드 이벤트

사용자의 키보드 입력에 반응합니다.

- `keydown`: 키를 누르는 순간 (연속 발생)
- `keyup`: 키에서 손을 떼는 순간
- **속성 차이**:
  - `event.key`: 실제 입력된 문자 (예: 'A', 'Enter')
  - `event.code`: 물리적인 키 위치 코드 (예: 'KeyA', 'Enter')

---

## 💡 핵심 요약

1.  **표준 준수**: 이벤트 등록은 항상 `addEventListener`를 사용하자.
2.  **효율성**: 자식 요소가 많다면 부모에게 이벤트를 맡기는 **이벤트 위임**을 활용하자.
3.  **세밀한 제어**: `preventDefault`로 기본 동작을 제어하고, `stopPropagation`으로 의도치 않은 버블링을 끊어주자.
