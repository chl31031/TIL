# 🟨 JS 생성자 함수, 프로토타입 및 표준 내장 객체 

### 1. 생성자 함수 (Constructor Function)
객체를 생성하기 위한 템플릿 역할을 하는 함수입니다.

* **규칙**: 이름의 첫 글자를 대문자로 시작(PascalCase)하며, `new` 키워드와 함께 호출합니다.
* **인스턴스 생성 3단계**:
    1. **빈 객체 생성 및 this 바인딩**: 암묵적으로 빈 객체가 생성되고 `this`에 할당됨.
    2. **초기화**: `this`에 바인딩된 객체에 프로퍼티를 추가함.
    3. **반환**: 완성된 객체(`this`)가 암묵적으로 반환됨.
* **주의사항**: `new` 없이 호출하면 일반 함수로 동작하여 `this`가 전역 객체를 가리키게 됨(전역 오염).
    * **안전장치**: `new.target`을 사용하여 `new` 없이 호출해도 생성자 함수로 동작하도록 방어 코드를 작성할 수 있음.

### 2. 프로토타입 (Prototype)
자바스크립트는 '클래스 기반'이 아닌 **'프로토타입 기반'** 상속 언어입니다.

* **[Prototype]**: 모든 객체가 가진 내부 슬롯으로, 다른 객체를 가리키는 연결고리입니다.
* **상속**: `student` 객체가 `user` 객체를 상속받으면, `user`의 메서드를 자신의 것처럼 사용 가능합니다.
* **특징**:
    * **메서드 호출**: `this`는 항상 메서드를 '호출한 주체'를 가리킵니다.
    * **쓰기 제한**: 프로토타입에 있는 프로퍼티를 수정하려 하면 프로토타입이 변하는 게 아니라, 자기 자신에게 새로운 프로퍼티가 생성됩니다.
* **생성자 함수와 프로토타입**:
    * `Student.prototype = user;` 처럼 설정하면 `new Student()`로 만들어진 객체의 `__proto__`가 `user`를 가리키게 됩니다.

### 3. 배열 (Array)
여러 개의 값을 순차적으로 나열한 자료구조입니다.

* **생성**: 배열 리터럴 `[]`을 사용.
* **주요 메서드**:
    * **추가/제거**: `push`/`pop` (뒤에서), `unshift`/`shift` (앞에서).
    * **검색**: `indexOf` (인덱스 반환, 없으면 -1), `includes` (존재 여부 true/false).
    * **조작**:
        * `slice(start, end)`: 원본 유지하며 특정 범위를 복사하여 반환.
        * `splice(index, count, add...)`: 원본 수정하며 요소 제거 및 추가.
    * **기타**: `join` (문자열 결합), `reverse` (순서 뒤집기).

### 4. 표준 내장 객체 (Standard Built-in Objects)

#### ① String (문자열 처리)
* **검색**: `.indexOf()`, `.includes()`
* **추출**: `.slice(start, end)`
* **변환**: `.split('#')` (배열화), `.trim()` (공백 제거), `.toUpperCase()` / `.toLowerCase()`

#### ② Math (수학 연산)
* **랜덤**: `Math.random()` (0~1 사이 소수)
* **정수화**: `Math.floor()` (내림), `Math.round()` (반올림), `Math.ceil()` (올림)
* **활용**: `Math.floor(Math.random() * 10) + 1;` (1~10 사이 랜덤 정수)

#### ③ Date (날짜와 시간)
* **생성**: `new Date()`
* **로컬 형식**: `.toLocaleString("ko-KR")`
* **정보 추출**: `.getFullYear()`, `.getMonth() + 1` (0부터 시작하므로 +1 필수), `.getDate()`
