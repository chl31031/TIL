# 🟨 JavaScript 객체, 함수 및 스코프

### 1. 반복문 제어 (Loop Control)
* **`continue`**: 현재 진행 중인 반복 회차를 중단하고, 다음 반복 회차로 넘어갑니다.
    ```for (let i = 1; i <= 3; i++) {
    if (i === 2) {
        continue; // ⚡️ 여기서 바로 i++(다음 회차)로 점프!
    }
    console.log(i + " 출력"); // i가 2일 때는 이 코드가 통째로 무시됨
    }

    // 출력 결과:
    // 1 출력
    // 3 출력 (2는 건너뜀!)
    ```

* **`break`**: 반복문을 즉시 완전히 종료하고 빠져나갑니다.
* **`for...of` (ES6)**: 배열이나 이터러블 객체의 요소를 순회할 때 사용하며, 인덱스가 아닌 '값'에 직접 접근하여 가독성이 높습니다.
> *이터러블(Iterable): 반복 가능한 객체를 뜻함.

### 2. 객체 (Object)
자바스크립트는 객체 기반 언어이며, 원시 값을 제외한 모든 것(함수, 배열 등)은 객체입니다.

* **구조**: 0개 이상의 `프로퍼티(Property)`로 구성된 집합입니다.
    * **Key**: 프로퍼티를 식별하는 이름.
    * **Value**: 프로퍼티에 저장된 값 (함수일 경우 **메서드**라고 부름).
    >프로퍼티(Property): 객체 지향 프로그래밍과 자바스크립트 등에서 객체 상태나 속성을 나타내는 키(key)와 값(value)의 쌍이다.
* **프로퍼티 접근법**:
    1. **마침표 표기법 (`.`)**: 일반적인 식별자 규칙을 준수할 때 사용.
    2. **대괄호 표기법 (`[]`)**: 키가 변수이거나 식별자 규칙을 위반할 때(예: `dash-key`) 필수 사용. (문자열 키는 반드시 따옴표 필수)
* **동적 조작**:
    * **갱신/추가**: 존재하면 갱신, 존재하지 않으면 동적으로 추가됨.
    * **삭제**: `delete obj.key`를 사용하여 삭제.
    * **존재 확인**: `'key' in obj` 연산자를 사용하여 boolean 값 반환.
* **객체 순회**: `for...in` 루프를 사용하여 객체의 모든 키를 순회.

### 3. 함수 (Function)
자바스크립트 함수는 **일급 객체**입니다. 즉, 값처럼 변수에 할당하거나 인자로 전달할 수 있습니다.

* **함수 호이스팅 (Hoisting)**:
    * **함수 선언문**: 런타임 이전에 엔진이 먼저 실행하여 선언문 이전에도 호출 가능.
    * **함수 표현식**: 변수 할당 시점에 런타임에 평가되므로 선언 이전 호출 불가.
* **매개변수(Parameter)와 인수(Argument)**:
    * 매개변수는 함수 내부에서만 유효한 지역 스코프를 가짐.
    * 인수가 부족하면 `undefined` 할당, 초과하면 첫 번째부터 매칭 후 나머지는 무시됨.
    * **기본값**: `function(name = '아무개')` 형태로 인수가 없을 때의 기본값 설정 가능.
* **반환문 (return)**:
    * 값을 반환하고 함수를 즉시 종료(조기 종료)시킴.
    * 생략하거나 명시하지 않으면 기본적으로 `undefined` 반환.

### 4. 변수 선언의 진화 (var vs let vs const)

#### var의 문제점 (ES5 이전)
1. **중복 선언 허용**: 실수로 변수 값을 덮어써서 버그 발생 위험 높음.
2. **함수 레벨 스코프**: if/for문 안의 변수가 밖에서도 유효하여 전역 변수 오염 발생.
3. **변수 호이스팅**: 선언 전에 참조가 가능하여 코드 예측이 어려움.

#### ES6 이후 (let, const)
* **`let`**: 중복 선언 금지, 블록 레벨 스코프(`{}`) 지원, 호이스팅이 일어나지 않는 것처럼 동작(TDZ).
* **`const`**: 선언과 동시에 **초기화 필수**, 재할당 금지. 
    * 단, 객체의 재할당은 불가능해도 **객체 내부 프로퍼티 수정은 가능**.

---

### 5. 스코프 (Scope) 및 변수 사용 원칙
* **스코프 계층**: 
    * `전역(Global)` > `블록(Block, {})` > `지역(Function)`
    * 하위(안쪽) 스코프는 상위 스코프에 접근할 수 있으나, 반대는 불가능함.

#### 💡 변수 선언 3원칙
1. 기본적으로 모든 변수는 `const`로 선언한다.
2. 값이 반드시 바뀌어야 하는 경우(예: 카운터)에만 `let`을 사용한다.
3. `var`는 절대로 사용하지 않는다.
