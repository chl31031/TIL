# ☕ Java — 자바 실행 원리 및 기본 개념 정리

## 1. JVM / JRE / JDK 관계

자바 실행 환경은 계층 구조로 이루어져 있으며, 개발과 실행에 필요한 도구가 다릅니다.

- **JVM (Java Virtual Machine)**: 자바 바이트코드를 실행하는 가상 머신. OS에 독립적인 실행을 가능하게 하며 메모리 관리(GC)를 담당합니다.
- **JRE (Java Runtime Environment)**: 자바 실행 환경. `JVM + 자바 표준 라이브러리`로 구성됩니다.
- **JDK (Java Development Kit)**: 자바 개발 키트. `JRE + 개발 도구(javac, 디버거 등)`를 포함하며 개발자는 반드시 JDK를 설치해야 합니다.

**[구조]**
`JDK` ⊃ `JRE` ⊃ `JVM`

---

## 2. 자바 컴파일 과정과 바이트코드

자바는 "Write Once, Run Anywhere" 정신에 따라 2단계 변환 과정을 거칩니다.

1.  **소스코드 작성**: `.java` 파일 작성
2.  **컴파일**: `javac` 컴파일러가 소스코드를 **바이트코드(`.class`)**로 변환 (JVM이 이해하는 중간 언어)
3.  **실행**: JVM이 바이트코드를 읽어 해당 OS가 이해할 수 있는 기계어로 변환 후 실행

---

## 3. 자바 메모리 구조 (Runtime Data Areas)

JVM은 메모리를 효율적으로 관리하기 위해 용도에 따라 영역을 나눕니다.

| 영역                | 설명                                                                     |
| :------------------ | :----------------------------------------------------------------------- |
| **메서드(Method)**  | 클래스 정보, static 변수, 상수 등 저장. JVM 시작 시 생성됨.              |
| **힙(Heap)**        | **객체와 배열**이 생성되는 공간. 가비지 컬렉션(GC)의 주요 대상.          |
| **스택(Stack)**     | 메서드 호출 시 생성되는 지역 변수, 매개 변수 저장. 스레드별로 독립 생성. |
| **PC 레지스터**     | 현재 실행 중인 JVM 명령어의 주소 저장.                                   |
| **네이티브 메서드** | 자바 외 언어(C, C++)로 작성된 코드를 위한 스택.                          |

---

## 4. 기본형(Primitive) vs 참조형(Reference)

### ① 기본형 (Primitive Type)

- **스택 영역**에 실제 **값 자체**를 저장합니다.
- 종류: `byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean` (총 8개)

### ② 참조형 (Reference Type)

- 실제 객체는 **힙 영역**에 저장되고, **스택 영역**에는 객체의 **주소(참조값)**만 저장됩니다.
- 기본형 8개를 제외한 모든 타입(String, 배열, 클래스 등)이 해당됩니다.

---

## 5. Wrapper 클래스 및 오토박싱

기본형 데이터를 객체로 취급해야 할 때(예: 컬렉션 프레임워크 사용 시) 사용합니다.

- **매칭**: `int` → `Integer`, `char` → `Character`, `boolean` → `Boolean` 등
- **오토박싱(Auto-boxing)**: 기본형을 자동으로 Wrapper 클래스로 변환 (`Integer num = 10;`)
- **언박싱(Unboxing)**: Wrapper 클래스를 자동으로 기본형으로 변환 (`int n = num;`)

---

## 💡 핵심 요약

1.  **독립성**: JVM 덕분에 OS에 상관없이 동일한 `.class` 파일을 실행할 수 있다.
2.  **메모리**: 객체는 Heap에, 변수는 Stack에 저장되는 구조를 이해하는 것이 중요하다.
3.  **데이터 비교**: 기본형은 `==`로 값을 비교하지만, 참조형은 내용 비교 시 반드시 `.equals()`를 사용해야 한다.
